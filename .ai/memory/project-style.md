# Project Style Memory

- Repository purpose: reusable FiveM resource template, not a gameplay framework replacement.
- Primary UI stack: Svelte 5 + Vite under `resource/ui/`.
- Thai-language content is a first-class requirement.
- Prefer reusable HTML/CSS/SVG components; raster assets are artwork only.
- Use approved design tokens and screen specifications before adding visual variants.
- UI work follows wireframe → visual design → implementation → review → refinement.
