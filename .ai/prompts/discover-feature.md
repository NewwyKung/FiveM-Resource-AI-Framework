# Discover a Resource or Feature

Use `.ai/skills/discover-requirements/SKILL.md`.

Do not implement yet.

Inspect existing memory, feature registries, decisions, specifications, and relevant source first. Ask only material questions in small coherent rounds. For each unclear decision, offer concrete options and recommend a default with rationale.

Capture the approved result in:
- `.ai/memory/requirements/<resource-or-feature>.md`
- `.ai/features/<feature>.md`
- relevant contract registries
- `docs/ui-spec/<screen>.md` when UI is required

Begin implementation only after the user approves the brief or explicitly authorizes recommended defaults.
