# Prompt Library

Use these as short task entrypoints. The repository rules and skills remain the source of truth.

## Create resource
`Use .ai/skills/create-resource/SKILL.md to create <resource> with <requirements>. Work on <branch>.`

## Add feature
`Use .ai/skills/add-feature/SKILL.md to add <feature>. Update its feature and contract registries.`

## Design UI
`Use wireframe-ui, then design-ui. Do not implement until the wireframe status is Approved.`

## Implement UI
`Implement the approved screen specification using implement-ui. Do not redesign it.`

## Review UI
`Review the running UI or screenshots using review-ui and record evidence-based findings.`

## Security review
`Use review-security and prioritize findings by exploitability and impact.`
