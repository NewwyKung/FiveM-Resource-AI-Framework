# v0

- Capability: `design-generation`
- Resource: `v0 app / v0 Platform API`
- Selected in: not selected; design-time only
- Runtime adapters:
  - Client: none
  - Server: none
- Verification: `documented` from official v0 Platform API documentation on 2026-08-05
- Source: https://v0.app/docs/api/platform/overview

## Operation

`Design.GenerateWireframe(options)`

```json
{
  "name": "Design.GenerateWireframe",
  "runtime": "build",
  "arguments": [
    { "name": "brief", "required": true, "contract": "ApprovedWireframeBrief" },
    { "name": "references", "required": false, "contract": "ApprovedVisualReferences" }
  ],
  "sideEffects": ["sends approved prompt and references to an external service", "creates an external chat/version"],
  "returns": "WireframeProposal",
  "errors": ["PROVIDER_UNAVAILABLE", "AUTHENTICATION_FAILED", "INVALID_RESPONSE", "RATE_LIMITED"],
  "dependencies": ["approved external-data use", "v0 tool or V0_API_KEY"],
  "unsupportedWith": ["FiveM runtime activation", "unapproved secrets or private source upload"]
}
```

## Option matrix

| Option | Type | Required | Default | Runtime | Conditions / dependencies |
|---|---|---:|---|---|---|
| `brief` | object/text | yes | none | build | Include purpose, regions, states, safe area, target viewports, and constraints. |
| `references` | images/links | no | none | build | Send only references approved for external processing. |
| `mode` | `manual` or `api` | no | `manual` | build | API mode requires a secret supplied through the environment, never the repository. |

## Return contract

- Success: layout proposal, preview/screenshots, and optionally generated web code.
- Failure: stable local error classification; do not silently skip the wireframe phase.

## Provider mapping

- Manual: submit the compact brief in the v0 app and attach only approved references.
- API: create a chat/message through the v0 Platform API using `V0_API_KEY` from the operator environment.
- Normalize only approved layout regions, measurements, states, and references into `docs/ui-spec/<screen>.md`.

Do not copy generated React, Next.js, Tailwind, dependencies, or transport code directly into the Svelte FiveM resource.

## Limitations

- v0 is not callable unless the active agent exposes a v0 tool or the owner explicitly configures API access.
- Generated code is a proposal and may not follow FiveM NUI, Svelte, responsive sizing, focus, or cleanup contracts.
- External preview behavior is not evidence that the UI works in FiveM CEF.

## Failure behavior

- Missing tool/API: fall back to `.ai/skills/wireframe-ui/SKILL.md` locally.
- Invalid response: keep wireframe status unapproved and report the missing decisions.
- Missing credential: request environment configuration; never create or store a key in the repository.
