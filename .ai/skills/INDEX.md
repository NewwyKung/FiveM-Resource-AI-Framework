# Skill Index

Read one primary skill per task. Add a second only when the task genuinely spans domains.

| Task | Skill |
|---|---|
| Start or scaffold a new resource | `create-resource/SKILL.md` |
| Add a feature to an existing resource | `add-feature/SKILL.md` |
| Design a new UI or major redesign before coding | `design-ui/SKILL.md` |
| Implement an approved UI specification | `implement-ui/SKILL.md` |
| Build/change NUI when design and integration are combined | `create-nui/SKILL.md` |
| Audit UI quality and design-system compliance | `review-ui/SKILL.md` |
| Apply targeted corrections from a UI review | `refine-ui/SKILL.md` |
| Debug a defect or incident | `debug-resource/SKILL.md` |
| Review security and fault cases | `review-security/SKILL.md` |
| Prepare production release | `release-resource/SKILL.md` |

## UI routing
- New screen or unclear visual direction: `design-ui` first.
- Approved screen spec: `implement-ui`.
- Existing screen audit: `review-ui`.
- Approved review findings: `refine-ui`.
- Small NUI integration change without design work: `create-nui`.
