# UI Component Registry

Source components are under `ui/src/lib/`. Read the component source before changing its API.

| Component | Typical use |
|---|---|
| Avatar | Player/profile identity |
| Badge, Chip, RankBadge, StatBadge | Compact status/metadata |
| Button, IconButton | Actions |
| Input, Select, Dropdown | Form input and selection |
| Checkbox, Radio, Toggle | Choice controls |
| Tabs, NavBar, BottomNav, Pagination, StepIndicator | Navigation and progress |
| Card | Grouped content surface |
| Modal, Toast, Tooltip | Feedback and overlays |
| ProgressBar, Rating, CurrencyPill | Game data display |
| Icon | Shared icon rendering |
| ComponentShowcase | Development reference only |

Create `<Component>.md` from `TEMPLATE.md` when a component gains a stable public API, multiple variants, or non-obvious accessibility behavior.
