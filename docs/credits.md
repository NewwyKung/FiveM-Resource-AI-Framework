# Credits and Development Background

## Byte Labs Studio

Special thanks to [Byte Labs Studio](https://github.com/Byte-Labs-Studio) and their [BL Svelte Template](https://github.com/Byte-Labs-Studio/bl_svelte_template).

This project does not reuse their UI design or UI components. Their work inspired developer-experience ideas around FiveM NUI development, including browser-side debugging, reusable NUI event helpers, disposable listeners, fallback resource names, and consistent local workflows.

See [`docs/reference/bl-svelte-template-review.md`](reference/bl-svelte-template-review.md) for the reviewed concepts and project decisions.

## AI-assisted development

The AI-facing skills, rules, recipes, memory structure, and supporting workflows were developed through a multi-model process.

Kimi K2.6 was used to help organize broad FiveM engineering knowledge and best-practice material. ChatGPT was used to review, normalize, summarize, and transform that material into bounded skills, rules, recipes, matrices, and repository structure. Claude has also been used extensively for day-to-day development and review.

These acknowledgements describe the author's workflow and personal experience. They are not sponsorships or endorsements, and no model output should be trusted without validation.
