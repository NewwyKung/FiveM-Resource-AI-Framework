## Runtime inventory decisions

- Move `fxmanifest.lua`, `client/`, `server/`, `shared/`, `config/`, `ui/`, and the HTML placeholder into `resource/`.
- The three non-empty files under `config/functions/` only initialize runtime namespaces. Move their concepts to `resource/shared/lib/config.lua`, `resource/client/lib/config.lua`, and `resource/server/lib/config.lua`.
- Remove empty duplicate placeholders `config/functions/config.client.functions.lua` and `config/functions/config.server.functions.lua`.
- Keep owner-editable values under `resource/config/`; do not create runtime-specific config subfolders.
- Preserve the NUI bridge, debug helper, feature state helper, empty Svelte shell, responsive formula, and committed package lock.
