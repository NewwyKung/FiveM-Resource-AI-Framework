# Support

This repository is a hobby project maintained in spare time.

Use GitHub Issues for reproducible bugs, documentation problems, and focused feature requests. Include the resource version, server artifact, framework/providers, reproduction steps, expected behavior, actual behavior, and relevant logs with secrets removed.

Use GitHub Discussions when available for broad ideas, usage questions, and architecture conversations.

Before opening a report, check `README.md`, `README_TH.md`, `FAQ.md`, `docs/`, and existing issues.

Support, compatibility fixes, and response times are not guaranteed. Clear reports and small reproducible examples are much easier to investigate.
